# Parlor Worship Website

Complete static website starter built from the approved Parlor Worship direction.

## Pages
- index.html
- about.html
- gatherings.html
- worship.html
- stories.html
- resources.html
- contact.html

## Structure
- css/base.css — variables, reset, reusable utilities
- css/style.css — components and page styling
- css/responsive.css — tablet/mobile layouts
- js/main.js — navigation, FAQ, newsletter demo, countdown
- images/ — SVG placeholder artwork ready to be replaced with final photography
- assets/ — future icons/fonts
- videos/ — future media

## Run locally
Open `index.html` in a browser, or use VS Code Live Server for the best local development experience.

## Production notes
Replace the SVG placeholder artwork with approved Parlor Worship photography.
Update event dates, contact details, social links and media URLs before launch.
The newsletter and contact form are frontend demonstrations and require a backend/form service before production.

YouTube footer URL is currently a functional placeholder (`https://www.youtube.com/`); replace it with the actual channel URL before launch.
