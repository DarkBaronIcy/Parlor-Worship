# Parlor Worship Website

Complete static website starter built from the approved Parlor Worship direction.

## Pages
- index.html
- about.html
- gatherings.html
- worship.html
- stories.html
- resources.html

## Structure
- css/base.css — variables, reset, reusable utilities
- css/style.css — components and page styling
- css/responsive.css — tablet/mobile layouts
- js/main.js — navigation, FAQ, newsletter demo, countdown
- images/ — pictures, hero 
- assets/ — icons/fonts
- videos/ — media
